# Лабораторна робота №1: Іплементація та маніпуляції основними типами та структурами даних у Python

Репозиторій містить виконання лабораторної роботи з вивчення базових структур даних Python, їх властивостей, закономірностей використання та оцінки алгоритмічної складності.

## Структура проєкту

- `task1.py` — Завдання 1. Списки: індексація, зрізи та мутації.
- `task2.py` — Завдання 2. Кортежі та «розпакування» даних.
- `task3.py` — Завдання 3. Словники та облік частот / довідників.
- `task4.py` — Завдання 4. Множини: унікальність та операції над наборами.
- `task5.py` — Завдання 5. Алгоритмічна складність і обґрунтування вибору структури.
- `main.py` — Головний скрипт для послідовного запуску всіх завдань.

## Запуск

Для запуску всіх завдань виконайте в терміналі:

```bash
python main.py
